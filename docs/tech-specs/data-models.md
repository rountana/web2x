# Data Models

## PostgreSQL Tables

Schema defined in `apps/api/src/db/schema.ts`. All tables use UUID primary keys. Child tables cascade-delete when the parent article is deleted.

---

### `workspaces`

Named containers that scope all articles and AI features for a given anonymous user.

| Column | Type | Notes |
|---|---|---|
| `id` | uuid PK | `gen_random_uuid()` |
| `user_id` | text NOT NULL | Anonymous ID from `x-anon-id` header |
| `name` | text NOT NULL | User-editable label (max 100 chars) |
| `created_at` | timestamptz DEFAULT now() | |
| `updated_at` | timestamptz DEFAULT now() | Updated on rename |

**Constraints:** Users cannot delete their last workspace (enforced at the API layer).

---

### `articles`

Core record created for every ingested URL, PDF, or markdown document. Always belongs to a workspace.

| Column | Type | Notes |
|---|---|---|
| `id` | uuid PK | `gen_random_uuid()` |
| `user_id` | text | Anonymous ID from `x-anon-id` header; nullable |
| `workspace_id` | uuid FK → workspaces | NOT NULL; CASCADE DELETE |
| `source_url` | text NOT NULL | Original URL (or synthetic value for PDF/markdown ingestion) |
| `title` | text DEFAULT '' | Extracted from content or provided by user |
| `raw_text` | text DEFAULT '' | Markdown stripped to plain text; used as LLM input |
| `markdown_content` | text DEFAULT '' | Turndown-converted Markdown; used for rendering |
| `word_count` | integer DEFAULT 0 | Word count of raw_text |
| `extracted_at` | timestamptz | Set when status transitions to `ready` |
| `status` | enum | `pending` → `ready` or `failed` |
| `error_message` | text | Populated on failure; cleared on retry success |
| `created_at` | timestamptz DEFAULT now() | |

**Status lifecycle:**
```
pending  ──(ExtractionWorker succeeds)──►  ready
         ──(ExtractionWorker fails)──────► failed
```

---

### `article_chunks`

Text chunks with vector embeddings, generated by `ChunkingWorker` after an article reaches `ready`.

| Column | Type | Notes |
|---|---|---|
| `id` | uuid PK | |
| `article_id` | uuid FK → articles | CASCADE DELETE |
| `chunk_index` | integer | 0-based ordering |
| `content` | text | 1500-char slice of `markdown_content`, 200-char overlap |
| `embedding` | vector(768) | nomic-embed-text-v1.5 embedding; nullable until embedded |
| `created_at` | timestamptz | |

**Index:** HNSW on `embedding` using `vector_cosine_ops` — enables fast ANN search in the chat route.

**Chunking strategy:** Paragraph boundaries preferred (`\n\n`), then sentence boundaries (`. `), then hard split. Old chunks are deleted before re-embedding (idempotent).

---

### `summaries`

AI-generated summary. One per article (idempotent — not regenerated if exists).

| Column | Type | Notes |
|---|---|---|
| `id` | uuid PK | |
| `article_id` | uuid FK → articles | CASCADE DELETE |
| `key_points` | jsonb | `string[]` — 3–5 bullet strings |
| `overview` | text | One-paragraph prose summary |
| `generated_at` | timestamptz | |

---

### `decks`

AI-generated flashcard deck. One per article.

| Column | Type | Notes |
|---|---|---|
| `id` | uuid PK | |
| `article_id` | uuid FK → articles | CASCADE DELETE |
| `cards` | jsonb | `FlashCard[]` — `{ front: string, back: string }[]` |
| `generated_at` | timestamptz | |

Default card count: 10. Configurable 5–20 per request.

---

### `quizzes`

AI-generated quiz. One per article.

| Column | Type | Notes |
|---|---|---|
| `id` | uuid PK | |
| `article_id` | uuid FK → articles | CASCADE DELETE |
| `questions` | jsonb | `QuizQuestion[]` (see type below) |
| `generated_at` | timestamptz | |

Default question count: 8. Configurable 3–15 per request.

---

## Relationships

```
workspaces (1)
    └──► articles (many)
              ├──► article_chunks (many)
              ├──► summaries      (0..1)
              ├──► decks          (0..1)
              └──► quizzes        (0..1)
```

All FKs use `ON DELETE CASCADE`. Deleting a workspace deletes all its articles and every derived record (chunks, decks, quizzes, summaries).

## Shared TypeScript Types

Defined in `packages/shared/src/index.ts`. Consumed by both `apps/api` and `apps/web`.


## Non-DB Storage

### PDF files

- **Location:** `uploads/pdfs/{uuid}.pdf` (configurable via `PDF_STORAGE_DIR`)
- **Lifecycle:** Generated on-demand, auto-deleted after 1 hour by `PdfCleanupWorker`
- **Access:** `GET /api/v1/pdfs/:filename` — UUID filename acts as an unguessable token

### Redis keys

| Key pattern | Purpose | TTL |
|---|---|---|
| `rl:ip:{ip}` | IP rate limit counter | 3600s |
| `rl:llm:{anonId}` | Per-user LLM rate limit counter | 3600s |
| BullMQ internal keys | Job queue state | Managed by BullMQ |

No article data is persisted in Redis.
